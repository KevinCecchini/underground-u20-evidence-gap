# Pubblicazione GitHub in 5 passaggi
1. Crea su GitHub un repository pubblico chiamato `underground-u20-evidence-gap` (senza README automatico).
2. Estrai questo ZIP. Apri un terminale dentro la cartella `UNDERGROUND_U20_FINAL_RELEASE`.
3. Esegui `git init`, `git add .`, `git commit -m "Research release v1.0"`.
4. Esegui `git branch -M main`, `git remote add origin https://github.com/TUO_USERNAME/underground-u20-evidence-gap.git`, `git push -u origin main` (seguendo il login GitHub).
5. Apri il link sul browser; verifica PDF, README e test. Sostituisci `[INSERISCI LINK REPOSITORY GITHUB]` nel post LinkedIn con il link reale.

**Prima del push:** controlla se vuoi mostrare pubblicamente il tuo nome, la tua affiliazione e se ogni fonte e file rispetta le condizioni di utilizzo. Non caricare gli oltre 900 MB dei JSON Wyscout grezzi o video di terzi.
